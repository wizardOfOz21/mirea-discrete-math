# Оформление определения

Отвечаем на языке пользователя. Используем только три подписи: «Область знания», «Определение», «Пример».

Области знания разделяем стрелками →, от общей к частной. После названия области с общепринятой аббревиатурой указываем её в скобках; предпочитаем наиболее распространённое обозначение.

После определения с новой строки в круглых скобках перечисляем названия параметров через точку с запятой, без пояснений.

После предложения примера с новой строки в круглых скобках перечисляем значения всех параметров в том же порядке, также через точку с запятой. Запятые внутри значений сохраняем. Допускаем короткие пояснения для однозначного сопоставления, избегаем избыточных подписей.

Предложение примера делаем кратким, без формул, вычислений, кода и лишних технических подробностей. В скобках допускаются числа, обозначения, массивы и другие структуры, необходимые для задания экземпляра.

## Пример оформления

Область знания

Математика → Дискретная математика → Теория графов

Определение

Простой неориентированный граф — пара из множества вершин и множества рёбер, каждое из которых является двухэлементным подмножеством множества вершин.

(множество вершин; множество рёбер)

Пример

Простой неориентированный граф с вершинами a и b и единственным ребром между ними.

({a, b}; {{a, b}})
