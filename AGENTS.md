# Договорённости для агентов

- Общаться с пользователем по-русски, кратко и по делу.
- README.md редактирует пользователь. Агент может менять его только по явному запросу пользователя на изменение README. Никогда не править README неявно: ни попутно с другими изменениями, ни для актуализации документации, ни по собственной инициативе. Общая просьба поработать над проектом не разрешает менять README.
- Всё, что нужно запомнить для следующих агентов — договорённости, предпочтения и контекст, который нельзя восстановить из файлов проекта, — записывать в AGENTS.md. Не использовать README для памяти агентов.
- Не дублировать здесь структуру проекта, содержимое заданий и другие сведения, которые уже следуют из репозитория.
- CLAUDE.md — символическая ссылка на AGENTS.md. Общие инструкции поддерживать в AGENTS.md, отдельную копию для Claude не создавать.
